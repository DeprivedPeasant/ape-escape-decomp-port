# glTF consumer and visual checks (generated)

Generated by `uv run --offline python tools/codex/report_gltf_qa.py` from actual exported-file preview results.

`python tools/codex/preview_gltf.py extract/gltf/008_0000BC/actor.gltf --clip set0_state05_run` renders a PNG contact sheet using the installed system Python/numpy (the uv environment does not contain numpy). The consumer reads the emitted glTF JSON, binary accessors, PNG texture pages, node transforms, animation samplers, joint indices, weights and inverse-bind matrices. No renderer dependencies are installed; no network/server/browser is used.

Each contact sheet has front, side, rear rows; columns sample the selected clip from start to end. Quaternion tracks use shortest-path SLERP. Colours/textures are shown as unlit base colour with glTF sRGB texture conversion; PSX lighting, environment mapping and translucent blending are outside this preview. The preview expects the exporter's RGBA PNG filter-0 output and is not a general-purpose glTF renderer.

## Full skinning regression

It compares the actual consumed inverse-bind/joint/weight output with export_model.posed_positions for raw poses and independent channel TRS matrices; source local vertices are not substituted into the consumer.
