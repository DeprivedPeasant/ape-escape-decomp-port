# Integer reverb network validation

Generated by `python tools/codex/check_reverb_network.py`; edit the generator and rerun.

`sp_reverb.h` implements the 22.05 kHz network: signed coefficients, intermediate shifts, saturating reflection/all-pass writes, the -32768 coefficient corner cases and SPU work-area address wrapping. It remains separate from the viewer until the 44.1 kHz conversion filters and mixer integration have independent validation.

The test loads all nine reverb presets directly from the original EXE table at 0x800B41D0. Impulse and full-range noise use original registers; stress cases replace IIR/APF coefficients with -32768 and start with random RAM. 27 cases compare 3,538,944 network steps (7,077,888 channel output samples) and 7,077,888 final RAM words with zero differences. 131072 steps per case exercise work-area wrapping.

Independent oracle: [pinned DuckStation SPU implementation](https://github.com/stenzek/duckstation/blob/697599c47a646a6cfcc4d246018adf4904d55001/src/core/spu.cpp). Extracted third-party code is used only in ignored test artifacts. The native core is independently written from arithmetic/register semantics. This corroborates network arithmetic against an emulator, not measured console output. Hardware reference: [PSX-SPX SPU documentation](https://psx-spx.consoledev.net/ps1/spu/soundprocessingunitspu/).

Remaining work: the 39-tap input/output FIR filters, one shared reverb input for music and effects, output-volume arithmetic, disabled-master behavior, hardware RAM interrupts and end-to-end Time Station listening/reference comparison. Existing demo reverb is still the earlier floating-point network and simple resampling. These tests do not claim full hardware audio fidelity.
