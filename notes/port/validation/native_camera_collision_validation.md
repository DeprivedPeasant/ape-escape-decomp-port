# Camera ground-clamp validation

Generated by tools/codex/check_camera_collision.py. 4000 cases, 6000 ordered ground queries and two missing-callback checks pass, zero failures. Full176slot bytes, normalize input vectors, square-root arguments and query coordinates match original executable instructions. Random signed extremes and squared-length/root/ground return values exercise wrapping, thresholds, byte saturation, rollback and timer state.

Callback results are deliberately supplied to isolate each routine; these tests do not validate VectorNormalSS, SquareRoot0, world geometry or the full follow camera. Missing callbacks return failure without slot writes. Sonnet implemented the bounded helpers; Codex reviewed and independently checked them.
