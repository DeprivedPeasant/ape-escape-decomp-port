# Combined reverb validation

Generated by tools/codex/check_reverb_pipeline.py. Sonnet5.5 implemented the composition wrapper; Codex reviewed and independently tested it.

All9originalEXEpresets, 54 cases and 3,538,998 stereo frames match the complete pinned DuckStation ProcessReverb output and final RAM with zero failures. The external function is extracted into ignored test artifacts; a scalar test adapter supplies its vector operations. No external algorithm code is included in the native production headers. Input impulse/noise/limits, signed gains and735/512callbackchunk sizes are covered. Base addresses, RAM, FIR filters and output gain are checked together.

Oracle [pinned SPU source](https://github.com/stenzek/duckstation/blob/697599c47a646a6cfcc4d246018adf4904d55001/src/core/spu.cpp). Emulator corroboration is not console measurement: master-disable/IRQ/RAMsharing/whole-song source mix fidelity remain unvalidated. Components are ready for separate mixer integration validation.
