# Actor animation timing and interpolation (generated)

Generated by `uv run --offline python tools/codex/check_animation.py`.

ActorAnimDecode (0x80014E34) and ActorAnimDecodeEntry (0x80014EF0) read 8-byte entries: first game frame, last game frame, key spacing, starting key. They select key floor((current-first)/spacing), then the next key as an interpolation neighbor. The fractional weight is the low 12 bits of floor((current-first)*4096/spacing). The next key can be outside the playable frame range; it must be read but must not extend the exported clip.

AnimDecodeLerp (0x80014FA0) interpolates packed Euler components separately, adjusting endpoints by 4096 only when their difference is outside [-2048,2048]. Weighted sums divide by 4096 toward zero, including negative root positions. The exporter now bakes each integer monkey game frame, converts that pose with Rz*Ry*Rx, and ends at (last-first)/fps. Player/enemy contiguous frame clips retain their existing sample timing.

Validated 11376 monkey clip associations, 3792 distinct packed sources, 77592 integer-frame poses. Independent raw-word arithmetic comparison failures: 0. Three hand-derived fixtures cover wrapped crossing, exact ±2048 ties and negative division.

11376 associations previously exported an extra neighbor span; correction removes up to 3 game frames from their duration. Source range and baked duration are recorded in animation extras.

Limits: glTF LINEAR quaternions interpolate between the baked poses. At integer game frames the exported Euler pose matches the decoded/interpolated values; subframe quaternion interpolation still differs from PSX Euler interpolation. Matrix sine/cosine calculations remain floating point. Player runtime speed, looping, transition blends and gameplay state changes are not clip metadata.
