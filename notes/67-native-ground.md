## Scope and evidence

`native_ground.c` reads original extracted area members directly. It reconstructs the terrain height portion of GetGroundHeight (0x80043400), preserving signed 16-bit differences, division toward zero, triangle selectors, slopes, surface attributes and sentinel results. Source exports from private read-only Ghidra are ignored under notes/decomp/codex/native-ground*.c.

The test oracle executes the actual original MIPS instructions from extract/disc/SCUS_944.23 using a small test-only integer interpreter with branch and load delay slots. It supplies the real LevelGrid/header data and hooks only GetSolidHeight to return 0x7FFF (no solids). No original code/data is embedded into committed files or used by the native renderer as emulated execution. This establishes terrain equivalence, not full collision parity.

## Recovered details

Area entries are the first 16 fixed 0x24-byte records of the area blob. Each contains nine 32-bit words: player xyz at +0, camera xyz at +0x0C, facing xyz at +0x18. AreaLoad sets the entry table pointer to the blob base; AreaGetEntryPoint indexes entry*0x24; PlayerPlaceAtEntry reads player xyz and the low halves of facing words. Area 01 entry 0 is player (1280,-1536,-3072), camera (1280,-2048,-4000), facing (0,0,4096). Y remains negative-up in original data, so rendering maps xyz to (x,-y,z)/256.

The terrain selector starts with `(localX < localZ)*2 | (512-localX < localZ)`. When cell bit11 is set it ORs 0x80 and `(cellWord >> 8) & 0x70`: the variant bits are original word bits12..14. Accepted selectors are 0/90/A0 (top), 1/A1/B1 (right), 2/92/C2 (left), 3/B3/C3 (bottom), written in hex. Others produce 0x4000 with zero slopes. This corrects the earlier notes/12 description of variant bits8..10; proposal is in the inbox.

Source bit0 controls terrain visibility, not probing. Terrain-disabled header bit1 yields 0x4000; ordinary points outside the half-open terrain rectangle return zero and cleared scratch data. Some disabled-grid slopes are uninitialized in the original; the oracle uses zero stack values for deterministic comparison, and the native API reports zero there.

## Remaining collision work

GetSolidHeight, stacked shape handlers, collider volumes, zone masks, water, wall pushes and dynamic props are not included in this terrain API. Returning terrain-only height must not be described as complete gameplay collision. Entry facing/render orientation and original player movement/state behavior still require integration validation.
