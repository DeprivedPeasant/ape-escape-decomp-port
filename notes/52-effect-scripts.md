# Effect particle script bytecode (generated)

Generated by `uv run --offline python tools/dump_effect_scripts.py`. Full game-data disassembly is kept gitignored at extract/codex/effect-scripts.txt/.json.

No extracted/decompiled code is committed. Opcode/operand facts are transcribed from switch(*pc-1) and actual pc increments, then validated on the EXE streams.

ExportCallers.java (tools/codex/ghidra_scripts) exported 33 roots/direct callers, including named overlay functions. Every direct SpawnEffectGroup call uses either the default table or one of the seven overlay tables below. Overlay-local types start at 200 (0xC8); table pointers are resolved in their own address space. The decompiler auto-label PTR_DAT_<script>_<table> contains BOTH a pointed-to address and the table address; the final address is the table location.

Encoding: little-endian u16 opcode; operands are 16-bit words (signed where arithmetic requires it). There is no byte opcode, length header, pointer jump or padding within an instruction. Opcodes absent from the interpreter switch are illegal: 0,5,6,7,28,29,50 and >52. END=4 terminates the slot; END_LOOP=3 closes a structured loop. WAIT opcodes yield; END is not a wait.

SpawnParticle passes script table 0x800B175C to SpawnEffectGroup, which invokes SpawnOneParticle for types <0x100. SpawnOneParticle sets slot+4 to table[type] for type<200, or table[type-200] otherwise. The default table runs through 0x800B1824 (null sentinel), before the group table at 0x800B1828. Types 0/1 are null, and type 8/9 share a stream. Additional type values are not assumed valid unless the table contains them.

Slot stride is 0x34, 100 slots at 0x800B9900. +0 active/type, +1 movement freeze flag, +2 anchor mode, +3 signed loop depth initially -1, +4 pc, +8/+0xC loop pc stack, +0x10/+0x11 loop counts, +0x12/+0x13 dimensions, +0x14 position (s16[3]), +0x1A fade, +0x1C velocity (s16[3]), +0x22 wait timer, +0x24/+0x28/+0x2C/+0x2E UV pairs, +0x26 CLUT, +0x2A TPAGE, +0x30 RGB/GPU command. ## Coverage limits

All streams in the default particle table and seven tables used by every known direct caller are accounted for. Group lists (kinds 0x32/0x33) and effect-object definitions are different formats and are not scripts for this interpreter. Raw bytecode without an absolute pointer to a known stream cannot be reliably distinguished from geometry. The direct caller audit finds no scripts in area blobs; unknown indirect calls or currently unused tables are not ruled out. No speculative scans are counted as validated scripts.
