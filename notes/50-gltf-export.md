# glTF actor export (generated)

Generated by `uv run --offline python tools/export_gltf.py audit`.

Commands: `spike`, `all`, `actor MEMBER OFFSET`, `check PATH`. Explicit source clips use `--clip NAME:OFFSET:FIRST:LAST` for raw player/monkey frames or `--channel-clip NAME:OFFSET:FIRST:LAST` for ModelPoseBones channel streams; OFFSET is the stream header address within the member, not the preceding clip table. Both options append to any automatically resolved clips; unassociated actors start with an empty clip list.
Outputs: `extract/gltf/MEMBER_OFFSET/actor.gltf`, `actor.bin`, and PNG pages under `tex/`.

The exporter imports export_model/vram without modifying them. Each source vertex belongs to one joint with weight 1. Corners are duplicated for UV/colour seams; quads split 0,1,2 / 2,1,3. Bone parent p refers to bone p-1; p=0 attaches to the synthetic skeleton root. For fixed player/monkey poses, bone 0 translation replaces its stored offset; channel poses retain stored offsets unless overridden. Bind rotations are identity and inverse binds undo accumulated offsets.

Angles use the existing packed decoder (10-bit x/z, 12-bit y field, all multiplied by 4). Local rotations are Rz*Ry*Rx. Coordinates reflect y and divide by 256 (chosen export scale, not proven metres). Quaternion vectors reflect as (-x,y,-z); winding is reversed. PNG UVs use (u/256,v/256). Nearest texture sampling, vertex colours and PBR roughness=1/metallic=0 approximate PSX materials; blend modes and environment mapping are not reproduced.

PlayerInit resolves ten state sets from member 008 header +0x14+i*0x10. States are 8 bytes (inclusive first/last frames and flags); animation stride is (bones+2)*4. Spike set 0 starts at 0x1035C; state 0 stand spans 0..28. Empty gadget sets are skipped. Frame times default to 30 fps (configurable); clip naming is numeric except established player states. LINEAR interpolation uses quaternion shortest paths between emitted samples; subframe interpolation approximates the game's Euler interpolation. Monkey integer-frame interpolation is baked as documented below and in notes/55-animation-timing.md.

All actors have their joint and vertex counts checked and an in-memory glTF built/validated. MonkeySpawnAll resolves model offsets (header words 2..4), 8-byte clip tables (words 6/7), and frame sets (words 8/9) relative to the monkey section. Monkey clips carry first/last game frames, keyframe spacing, and starting key index. The export reads the final interpolation neighbour but ends at the inclusive last game frame. AnimDecodeLerp wrapping, 12-bit blend weight and division toward zero are baked at every integer game frame before quaternion conversion. ZED +0x18 is the MODEL offset (ObjInitModel); +0x1C is the animation table offset. ZakoGetAnimTable reads a 4-byte header with u16 clip count, then count*4-byte first/last pairs followed by a ModelPoseBones channel stream. See notes/61-channel-animation.md for its descriptor-dependent stride and TRS channels. These corrected the earlier ambiguous +0x18 animation-data description in notes/22 and symbols.csv through the inbox. Zero clips means unresolved association, not zero source frames; unrelated actors in auxiliary data blobs require explicit --clip.
